# wpstatussignal-data

Snapshots of public Make WordPress activity (post titles, links and times, plus meeting times) for the WP Status Signal site. A scheduled GitHub Action in `courtneyr-dev/wpstatussignal` rewrites `latest.json` every 3 hours and adds a dated copy.

Source: make.wordpress.org REST API, the meetings calendar, and jobs.wordpress.net. Content belongs to its authors; each item links to its source.
